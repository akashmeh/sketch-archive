# SKETCH Archive

Create a premium, highly interactive website for my student technology and innovation club, SKETCH. I have attached our SKETCH Club magazine as the main source of truth for our branding, club information, domains, team structure, previous events and achievements, and I have also attached a retro computer/workstation illustration that should be the main visual inspiration for the website. Do not recreate the magazine as a website and do not make a generic modern startup/portfolio website. Instead, create an original retro-futuristic digital experience that combines the visual identity of the magazine with the atmosphere of the retro computer reference. The visual direction should use a dark brown/black textured background, burnt orange as the primary accent, warm cream/off-white typography, subtle grain and noise, condensed oversized display typography, outlined duplicate lettering, thin borders, grids, retro UI elements, CRT scanlines, subtle glow, shadows and analog imperfections. The website should feel like “SKETCH built a website inside a retro computer.” Start with a cinematic full-screen hero where a retro CRT computer/workstation inspired by the attached image is the main visual. The monitor should display the SKETCH identity and subtle animated retro UI elements. Use large typography such as “SKETCH”, “DESIGN. DEVELOP. DELIVER.” and “10 YEARS OF TURNING IDEAS INTO IMPACT.” Include a small “SCROLL TO ENTER →” interaction. Make the entire website scroll-driven and immersive, with a strong but smooth multi-layer parallax effect where the background grid, computer, foreground objects, artwork, textures and typography move at different speeds. Use GSAP/ScrollTrigger or another appropriate animation system for smooth scroll-based animations, image reveals, typography movement and depth transitions. Avoid excessive animations that make the site difficult to use. After the hero, create an interactive ABOUT SKETCH section rather than a normal text block. Use the attached magazine as the factual source. The magazine states that SKETCH was founded in 2015 and is a multidisciplinary, student-led community focused on creativity, technology, innovation, collaboration and practical implementation. Present this information creatively through an interactive visual timeline or retro computer interface showing the journey from 2015 to 2026 instead of a large paragraph. Make the user feel like they are discovering the story of SKETCH. Then create a visually striking 10-YEAR section. Since SKETCH was founded in 2015, create a live anniversary counter that dynamically calculates the elapsed time and displays years, months, days, hours, minutes and seconds. Make this look like a retro digital counter, CRT display or mechanical odometer rather than a normal statistics section. Display “2015 — 2026” and a short statement such as “A decade of ideas, experiments, people and impact.” Next create a REWIND section showcasing SKETCH's previous events. Do not use a generic three-column card grid. Make it feel like exploring an old archive, film reel or collection of memories. As the user scrolls, event photographs should reveal, move and overlap with event titles, dates, descriptions and outcomes. Use the actual events and information from the attached magazine, including The Rollercoaster of Hormones in Your 20s, Pixel N' Play, First Commit — A Workshop on GitHub Basics, Among Us — Control Room, Building Intelligent Products with AI, Pinnacle Hacks Partner, NXTGEN Hackathon — Texus '26 and Inauguration Day. Preserve factual information from the magazine and do not invent event details. Then create the DOMAINS section as a major interactive experience rather than a grid of cards. The domains in the magazine are Design, Sponsorship & Finance, Content & Documentation, Media & Marketing, Research & Development and O&PR. Present them as an interactive retro computer control panel with a heading such as “SELECT A DOMAIN”. When the user hovers over or clicks a domain, animate the interface and reveal that domain's description, visual identity and members. Make the selected domain expand dramatically while the other domains remain in the background. Then integrate MEET THE TEAM directly into this domain experience: selecting Design reveals the Design members, selecting R&D reveals the R&D members, selecting Media reveals the Media members, etc. Also create a separate CORE TEAM subsection using the leadership structure and names from the magazine. Use the available team photographs from the provided reference and present them using creative editorial compositions, irregular layouts, rounded retro frames, orange/cream borders, offset shadows and oversized typography instead of generic profile cards. Finally create an immersive REGISTER NOW section that feels like reaching the end of the retro computer experience. Show a CRT screen or terminal-style interface with text such as “READY TO JOIN SKETCH?” and “10 YEARS OF BUILDING. YOUR TURN TO CREATE.” followed by a large interactive “REGISTER NOW →” button. Make the button feel like a physical retro computer button or terminal command, with a blinking cursor, subtle CRT glow and scanlines. The button should be easy to replace with our actual registration URL. Throughout the website, use the attached magazine as the source of truth for SKETCH's content and use the retro computer image as inspiration rather than copying it. Do not invent people, achievements or event information. The website should be original and feel like a creative technology club rather than a corporate website. Use React/Next.js or Lovable's current recommended stack, with Tailwind CSS and an appropriate animation library. Make it fully responsive, performant and accessible. On mobile, simplify the parallax layers and convert complex hover interactions into touch-friendly interactions while preserving the visual identity. Include smooth section transitions so the page feels like one continuous journey: RETRO COMPUTER HERO → ABOUT → 10 YEARS → REWIND → DOMAINS → TEAM → REGISTER. Prioritize visual storytelling, typography, depth, interaction and atmosphere. The final result should be memorable enough to feel like a showcase website for a creative technology club, not simply a website containing information.
